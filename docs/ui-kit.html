1 · UI Kit

Design tokens & composants

Le UI Kit centralise toutes les décisions visuelles sous forme de variables CSS (design tokens). Chaque composant est construit à partir de ces tokens — aucune valeur codée en dur. Résultat : cohérence garantie entre le web (présentateur) et le mobile (participant), et un seul point de modification.

3 · Multi-périphériques

Caractéristiques d'affichage prises en compte

Chaque rôle utilise un périphérique différent dans un contexte différent. Le design s'adapte aux contraintes réelles de chaque situation d'usage — pas seulement à la taille de l'écran.

📱
Mobile — Participant
≤ 480px · portrait · Web responsive
  • Colonne unique, layout vertical, contenu prioritaire en haut
  • Cibles tactiles ≥ 48×48px (boutons de vote et réactions)
  • Actions principales dans la zone du pouce (bas de l'écran)
  • Thème sombre : confort en environnement peu éclairé (bar, salle)
  • Aucune saisie complexe — un code court, un tap pour voter
💻
Desktop — Présentateur
≥ 1024px · paysage · React web
  • Grille multi-colonnes : graphique + panneau latéral (QR, contrôles)
  • Densité d'information élevée : KPIs, questions, timer
  • Interactions souris : hover states sur boutons et lignes de tableau
  • Navigation persistante (sidebar) — absente du mobile
📺
Grand écran — Projection
≥ 1920px · TV / vidéoprojecteur
  • Contraste maximal : orange #D85A30 sur noir #0A0A0A
  • Typographie Sora agrandie — lisible à plusieurs mètres
  • QR code toujours visible pour rejoindre à tout moment
  • Pas d'interaction : affichage pur, mis à jour en temps réel
